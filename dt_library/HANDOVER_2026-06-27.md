## 8. Gotchas (save yourself time)
- Deploy = GitHub Desktop → Commit → Push (or CLI `git push origin main`), then wait ~1 min + hard-refresh.
- iCloud offloading + git: see §2. Verify file readability in bash before any bulk edit; the host-level Read/Edit tools work on offloaded files when bash can't.
- The sandbox **cannot delete** files on the iCloud Desktop ("Operation not permitted") — to remove a page, overwrite with a redirect stub or have Jaun delete it in Finder. Editing/creating works.
- Bulk header/branding edits touch 200–460 files — script them, validate (node --check on extracted inline scripts, div balance, marker counts), and **re-verify counts** afterward; offloaded files get silently skipped.
- When validating inline JS, exclude `type="application/ld+json"` blocks (region pages have SEO JSON-LD that isn't JavaScript and will false-fail a node check).
- exclusive-preview deploys via **Vercel CLI from its own folder**, NOT via the GitHub push — they're independent.
- Keep `@desert-tracks.com` emails and the `ol` login intact — functional, not branding.
